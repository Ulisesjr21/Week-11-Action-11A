CS110 Lecture Notes 


1. Classes and Objects
* Class: A blueprint used to create objects. 
* Object: An instance created from a class. 
* Variables: Store information such as speed, position, and color. 
* Methods (Functions): Contain instructions and actions. 
* Object-Oriented Programming (OOP): Organizes code using classes and objects.  
2. Programming Languages
* C#, C++, and Python support object-oriented programming. 
* Different languages share concepts like variables, methods, and logic. 
 3. Unity and Visual Studio

* Unity: A game engine used to create games and interactive applications. 
* Visual Studio: Used to write and debug C# code. 
* Unity uses C# for scripting, so our previous C# knowledge applies. 
* Unity handles graphics, objects, movement, and other game systems.  
4. How Game Engines Work
* C# scripts define how objects behave. 
* Variables control properties like movement speed and rotation. 
* Methods perform actions such as moving or changing an object's color. 
* The game engine processes the code and displays the results.  
5. Git and GitHub
* Git: Tracks changes made to code and project files. 
* GitHub: Stores projects online and allows teams to collaborate. 
* Unity and Visual Studio can work with Git for version control.  
6. User Interfaces (UI)
* HTML/CSS: Used to design web interfaces. 
* WPF: Used to build Windows desktop applications. 
* Unity UI Toolkit: Used to create interfaces inside Unity. 
* These technologies share similar design and layout concepts.  
7. AI and Problem-Solving
* AI helps programmers write code and create applications. 
* Programmers must still understand, test, and improve the code. 
* Problem-solving and understanding how systems connect are important programming skills.  
Main Idea
Programming is not just about memorizing code. It's about understanding how classes, objects, variables, methods, software, and hardware work together.
